InfraScan — Insta360 video → data (proof of concept)

Runs the infrascan stage-0 pipeline (stitch → frames → perspective views) on a RunPod GPU worker. Enter your endpoint + a reachable video URL.

POC note: this page calls the RunPod API directly with your key in the browser — fine for local testing, but for a real website put a small backend between the page and RunPod so the key never ships to users. Browser→RunPod may also be blocked by CORS; if so, use the curl commands in the README instead.
